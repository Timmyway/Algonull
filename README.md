# Algonull

Welcome to **Algonull**! This repository is a collection of algorithms implemented in both **JavaScript** and **Python**. It is a personal learning project where I tackle various algorithms to improve my understanding of programming, problem-solving, and computational thinking. 

The name **Algonull** reflects the humble beginning of my journey — starting from scratch, with no formal education in algorithms. I’m learning them as a self-taught programmer, taking the bull by the horns, and experimenting with solutions one step at a time.

## Why Algonull?

As someone who hasn't learned algorithms at school, I decided to teach myself by diving straight into coding these algorithms. I want to embrace the learning process, starting from the basics and building my knowledge piece by piece. This repo will grow as I explore more algorithms, implement them, and refine my understanding of computer science concepts.

## Algorithms Implemented

So far, the repo contains the following algorithms:

- **BubbleSort**
  - Basic implementation of the BubbleSort algorithm in both **Python** and **JavaScript**.
  - Tracking swaps during the sort process.
  - Includes unit tests to verify correctness.

## Directory Structure

The project contains two main directories:

- **`algo-js/`**: JavaScript implementations of algorithms.
- **`algo-py/`**: Python implementations of algorithms.

## Getting Started

### Prerequisites

To run the code, you’ll need:

- **Node.js** (for JavaScript)
- **Python 3** (for Python)

### Running the Algorithms

#### JavaScript

To run JavaScript files, use Node.js:

1. Navigate to the `algo-js` directory:
```bash
cd algo-js
node bubbleSort.js
```

**Python**
To run Python files:

1. Navigate to the `algo-py` directory:

```bash
cd algo-py
```

2. Run a script:

```bash
python bubbleSort.py
```

**Tests**
Tests are included to verify the correctness of the algorithms. You can run the tests for both languages.

#### JavaScript (Jest)
1. Install dependencies:

```bash
npm install
```

2. Run tests:

```bash
npm test
```

#### Python (unittest)
1. Run tests:
```bash
python -m unittest discover
```
